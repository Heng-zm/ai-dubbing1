# ai-dubbing1

## KhmerDub — AI Dubbing Studio for Khmer (iOS)

KhmerDub is an iOS application designed for localizing and dubbing videos and audio into natural spoken Khmer.

### Features
- 🎙️ **Speech Transcription**: Transcribe video/audio speech into text lines using OpenAI Whisper.
- 🇰🇭 **AI Translation & Script Polishing**: Translate dialogue into natural spoken Cambodian Khmer script with custom glossary support.
- 🗣️ **Voice Dubbing**: High-quality Khmer text-to-speech powered by Azure Neural Voices (Sreymom & Piseth) and Apple system Khmer voices.
- 🎬 **Multi-Track Audio Mixing & Export**: Compose dialogue over original background audio or replace original audio entirely, with volume normalization and automatic speech duration fitting.
- 📝 **Subtitle Generation**: Automatically generate and export synchronized `.srt` subtitles.
- 📱 **Photo Library & Files Sharing**: Save exported dubbed videos directly to Photos or share via Files.

### Build
Built for iOS 17.0+ using Xcode 16 and SwiftUI.
Automated builds and unsigned IPA releases are packaged via GitHub Actions.
